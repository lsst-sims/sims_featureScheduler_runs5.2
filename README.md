# sims_featureScheduler_runs5.2
Even more survey strategy simulations

Results often posted at:  https://usdf-maf.slac.stanford.edu/


runs:

`comp_survey`: The current default survey strategy, useful as a comparision for experiments.

`desi`:  Gathering extra u and g band visits in the DESI footprint before Y4.

`technical`:  Directory for technical debugging runs, usually not actual simulations of viable survey strategies.

`templates`:  Gathering 6 template images per band in Y1.

`templates_decdep`:  Gathering 6 template images and using a declination-dependent seeing limit.
